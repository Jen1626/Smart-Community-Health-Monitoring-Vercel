# Smart Community Health Monitoring — Vercel Demo

Static dashboard based on the project design: ESP32, pH, turbidity and DS18B20 temperature sensing, WiFi/LoRa, Firebase and Safe/Caution/High Risk classification.

The included dashboard uses simulated readings so it can run immediately on Vercel. Replace the demo data in `script.js` with Firebase Realtime Database integration when connecting the real ESP32 system.

Files: `index.html`, `style.css`, `script.js`.
